# Interview Simulation

Open-source AI-powered mock interview simulator.

> **Project status: architecture review.** The technology stack and technical design are being proposed before application development begins.

## Architecture proposal

The initial technical architecture is under review in a draft pull request. No implementation has been approved or shipped yet.

## What we are building

A self-hostable application where candidates can:
- Import a job description and CV; review and approve an AI-generated interview scenario.
- Attend an interactive voice mock interview powered by Azure Speech (STT/TTS) and a configurable LLM.
- Receive context-aware answer hints and post-interview performance feedback.
- Inspect interview transcripts, event logs, and an independent workflow audit export.

See the architecture proposal PR before choosing dependencies or scaffolding the application.
